04
MACHINE LEARNING · 2025–2026

Visualizations as Perceptual Textures

A perceptual modeling framework using Portilla-Simoncelli texture statistics to investigate how machine learning models perceive correlation in visualizations.

  • Built an LDA framework using 1,254-dimensional perceptual statistics.
  • Analyzed 1M+ data points across visualization types.
  • Compared computational sensitivity with human just-noticeable differences.
Python NumPy LDA PCA Plotly Vega-Lite

PERCEPTUAL MODELING · 2026

Perceptual Noise Modeling

Extending an LDA-based perception model with statistical noise to model human-like uncertainty in visualization judgments.

  • Introduced Gaussian perceptual noise into model decision-making.
  • Calibrated model noise against human threshold values.
  • Modeled sensitivity across correlation levels using psychometric functions.
Python NumPy LDA PCA Psychometrics
